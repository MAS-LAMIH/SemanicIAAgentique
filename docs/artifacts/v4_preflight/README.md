## Measurements and limits

Verified: operator monotonic elapsed time and process exit; raw stdout/stderr; CLI thread/turn IDs and error/reconnect events. Raw CLI events have no per-event collector timestamps in this test. No completed turn usage, token totals, actual model version, inference duration, billing, tool-call duration or supervision measurements available: null, not zero. No model tools were requested, but request/attempt counts must not be inferred from turn count or reconnect count. A timestamping event collector would be needed for reliable event arrival intervals; these do not isolate model compute from network waits.

Verified process deadline enforcement, including a 45-second CLI stop; Docker resource flags accepted, not stress-tested. Exact token, inference-request and leaf-tool-call caps not demonstrated. Submission cap can be controlled by operator receipt/acceptance of at most three immutable submissions; no receipt gate was built/tested here. CLI automatic retries mean one invocation is not one model request. Treat quotas as logged-only until admission enforcement is demonstrated or common amendments explicitly approved.

## Minimal arrangement / readiness

Nine serial fresh workers with separate filesystem mounts, home and model contexts; only sanitized condition assets and submission files. Protected evaluator/service container with private native storage, separate from worker-visible paths; share only loopback network namespace as demonstrated. Operator outside worker receives/hashes immutable submissions and stores all logs privately. No host workspace, .git, sibling mounts, Docker socket, evaluator source/storage or previous session history in workers. Remove each worker and reset service/state after settling pending requests.

Not ready: working model access and successful live usage export, then combined CLI-in-container preflight, remain blockers. Must approve/configure supported model routing/credentials without bypassing network policy, rerun harmless telemetry test, test per-session tool/model access and allowlists, and settle enforceable versus logged-only budget policy. Independent gate lock/review and investigator execution/unsealing authorization remain separate prerequisites; not granted here.

Scope limits: path probes are evidence of tested mount boundaries, not proof against kernel/container escape, hostile networking, arbitrary mount misconfiguration or operator leakage. No hostile escape attempted. Same network namespace exposes all API listeners in that namespace; keep native/admin endpoints off it. Only visible fixture loopback was tested. External egress to a model was not tested inside containers (workers intentionally network-none); future proxy/CA configuration and restricted API reachability need a dedicated check. Evaluator mount is read-only input, but a live worker can still change its own source mount: final scoring must consume an immutable copy after worker termination. Completion marker in this smoke test is not a security mechanism. Private verdicts/answers must never be relayed back to live integration agents. Image contains no CLI, so an identical pinned CLI image is still needed. Human supervision/active time must be logged explicitly; otherwise null.
